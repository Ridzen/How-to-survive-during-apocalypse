# Запуск и окружение

## Что нужно

- Docker Desktop (установлен 16.11.2026, WSL 2)
- Бот у @BotFather, токен в `.env` (`BOT_TOKEN=`). Токен только в `.env` —
  `.env.example` это шаблон без секретов, он попадает в git.

## Первый запуск Mini App

Старая база от бота-прототипа несовместима с новой схемой — удаляем её (там только
тестовый персонаж и карта).

```powershell
cd "D:\Baha\PythonProjects\TG How to survive"
docker compose down -v
docker compose up -d --build db migrate
docker compose run --rm --no-deps bot python -m scripts.seed_bishkek
docker compose up --build
```

1. удалить старую базу
2. создать таблицы и справочники (миграции)
3. загрузить карту: скрипт скачивает выгрузку OpenStreetMap по Кыргызстану с Geofabrik
   (~50 МБ) и берёт из неё Бишкек — районы, спец-объекты, бары, **все здания** (5–15 минут;
   без зданий — добавить `--skip-buildings`).
4. запустить игру. В логе бота: `Mini App: https://….trycloudflare.com`

В Telegram: `/start` → «Играть» или кнопка «Играть» слева от поля ввода.

## Каждый день

`docker compose up --build`. Адрес туннеля меняется при перезапуске, бот обновляет кнопку сам.
`--build` нужен после изменений кода: код копируется в образ при сборке.

## Постоянный адрес (ngrok)

Временный туннель `quick` (cloudflared) меняет адрес при каждом перезапуске — старые кнопки
«Играть» в чате перестают работать. Постоянный бесплатный адрес даёт ngrok:

1. Зарегистрироваться на ngrok.com (бесплатно).
2. В кабинете: **Your Authtoken** — скопировать токен; **Domains** — свой домен вида `abc-123.ngrok-free.dev`.
3. В `.env`:
   ```
   COMPOSE_PROFILES=ngrok
   NGROK_AUTHTOKEN=<токен>
   NGROK_DOMAIN=abc-123.ngrok-free.dev
   WEBAPP_URL=https://abc-123.ngrok-free.dev
   ```
4. `docker compose down` и `docker compose up --build`.

Минус бесплатного ngrok: при первом открытии Mini App показывается страница-предупреждение
ngrok, нужно нажать «Visit Site»; после этого 7 дней не спрашивает. Для бета-тестеров —
сервер со своим доменом.

## Сервер (с 18.11.2026)

Игра работает на сервере, ноутбук для игроков больше не нужен.

|---|---|
| Адрес | https://kakvyzhit.duckdns.org (админка — `/admin`) |
| Сервер | DigitalOcean, Лондон (LON1), 2 ядра / 2 ГБ / 60 ГБ, Ubuntu 24.04, $18/мес |
| IP | 46.101.43.246 |
| Домен | бесплатный DuckDNS (вход через Google/GitHub на duckdns.org) |
| HTTPS | Caddy, сертификат Let's Encrypt продлевает сам |
| Бэкап базы | каждую ночь в 03:30 UTC → `/opt/backups`, хранятся 14 дней |
| Папка игры на сервере | `/opt/kak-vyzhit` |

Почему так: Hetzner — дешёвые тарифы закончились; AdminVPS и FirstVDS (Казахстан) — нельзя
заказать или нужен казахский номер и карта; DigitalOcean принимает Visa/Mastercard
кыргызского банка. Франкфурт был занят, Лондон — ~100 мс от Бишкека, для игры незаметно.

**Обновление игры — одна команда на ПК** (папка проекта): `.\deploy.cmd "что изменилось"`.
Скрипт: git commit → push в приватный репозиторий `github.com/Ridzen/tg-how-to-survive` →
на сервере `git pull` и `docker compose up -d --build`. Пароль не спрашивает (SSH-ключ ПК добавлен
на сервер). Сервер читает репозиторий своим ключом «только чтение» (Deploy key `server`).
`.env` в git не хранится — ни с ПК, ни с сервера.

Пароль от сервера — только у владельца. Команды запуска и обновления — README кода,
раздел «Сервер (продакшен)». **Бот работает на сервере** — на ноутбуке `docker compose up`
с тем же токеном не запускать (два бота с одним токеном мешают друг другу); для разработки
завести второго бота.

## Админка

1. В `.env`: `ADMIN_PASSWORD=<длинный пароль>` (логин — `admin`, меняется `ADMIN_USERNAME`).
2. `docker compose up -d --build web`.
3. Открыть `http://localhost:8000/admin` или `https://<адрес ngrok>/admin`.

Пусто в `ADMIN_PASSWORD` — админка выключена. Адрес ngrok открыт в интернет, поэтому пароль
длинный и никому не передаётся. Изменения справочников подхватываются игрой за минуту.

## Отладка в браузере

`.env`: `DEV_AUTH=true` → `http://localhost:8000/?dev=1`. На сервере с игроками — только `false`.

## Проверка без прогулки

Режим «🚶 Оффлайн» есть у всех игроков: тап по карте, 1,4 м/с, засчитывается как прогулка.
`.env`: `TEST_WALK=true` добавляет в него скорости 3 и 12 м/с — быстрее дойти до нужного места.
Для игроков — только `false`.

## Тесты

`docker compose run --rm --no-deps bot python -m pytest`

## Бета-тест

Туннель с ноутбука — только для себя: адрес меняется, ноутбук должен быть включён.
Для бета-тестеров нужен сервер (VPS) с доменом: `WEBAPP_URL=https://домен`, без сервиса `tunnel`.

# Решения MVP

«Дизайн» — решил геймдизайнер (ответы в [[Открытые вопросы]]).

## Продукт и техника

| # | Решение | Кто | Почему |
|---|---|---|---|
| 1 | Сразу Mini App, бот только для входа; Mini App отдаём бета-тестерам | дизайн | карта и живой GPS невозможны в чате |
| 2 | FastAPI + PostgreSQL/PostGIS + чистый JS, карта MapLibre + OpenFreeMap | разработка | бесплатно, без ключей, легко читать |
| 3 | Миграции Alembic; старая база удаляется | разработка | менять структуру без потери данных; в старой только тест |
| 4 | Справочники (уровни, предметы, шансы) — таблицы в Postgres | дизайн | править без программиста |
| 5 | Туннель cloudflared для теста, сервер с доменом для беты | разработка | Telegram требует HTTPS |
| 6 | Токен бота только в `.env` | разработка | токен = пароль |

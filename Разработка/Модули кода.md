# Модули кода

Пути относительно `D:\Baha\PythonProjects\TG How to survive`.

## Вход

| Файл | Что делает |
|---|---|
| `app/main.py` | бот: `/start` и кнопка меню «Играть» |
| `app/bot/webapp.py` | откуда взять адрес Mini App: `WEBAPP_URL` или туннель |
| `app/web/main.py` | сервер Mini App |
| `app/web/api.py` | запросы экранов: персонаж, регистрация, позиция, рюкзак, карта |
| `app/web/auth.py` | проверка подписи Telegram |
| `app/config.py` | все настройки (см. README, раздел 7) |

## Админка — карта (21.11)

| Файл | Что делает |

Координаты 📡 — настоящее местоположение игроков: только для модерации и тестов |

## Экраны Mini App (`app/web/static`)

| Файл | Что внутри |
|---|---|
| `index.html` | экраны: создание персонажа, характеристики, пролог, убежище, карта; вкладки «База» и «Персонаж»; нижнее меню |
| `app.js` | логика экранов, живой GPS, Оффлайн (подтверждение, флажок 🏁), Онлайн (пульс, телепорт к базе), база, снаряжение, уведомления о луте |
| `app.js` → прилавок | одно окно для рынка, лавки выживших и бродячего торговца (`openShop`). Куда идёт сделка — по тому, что открыто на экране; если успели открыть другой прилавок, старый ответ отбрасывается (24.11: в «Лавке выживших» вылезала ошибка «Подойди к торговцу ближе — Нурдин…») |
| `app.js` → карточка «боевые числа» | 24.11: в рамке — здоровье полосой, плитки Урон / Крит / Уворот / Скорость, броня по зонам, прибор, «🏆 Рейтинг недели» | |
| `doll.js` | фигурка персонажа слоями: тело → штаны → обувь → верх → голова → оружие; у новых предметов — общий рисунок по слоту |
| `style.css` | оформление: тёмная тема, сепия на карте, цвета грейдов |
| `avatars/*.svg` | 4 аватара: m1 противогаз, m2 шапка и шарф, f1 капюшон и очки, f2 бандана |

# Нагрузка и масштабирование

**Цель:** 200–500 тыс. запросов в сутки — в среднем 3–6 в секунду, в пике в 5–10 раз больше.

## Откуда нагрузка

Главное — точки GPS: до 10 в минуту на активного игрока. 1000 игроков онлайн одновременно
≈ 170 запросов в секунду. Каждая точка — несколько быстрых запросов к базе по индексам.

## Что заложено

| Мера | Зачем |
|---|---|
| Клиент шлёт точку только при сдвиге на 15 м или раз в 50 с | в разы меньше запросов, чем «каждую секунду» |
| Сервер не принимает точки чаще раза в 6 с | защита от перегрузки и накрутки |
| Геоиндексы по точкам и контурам | «объект рядом» ищется по индексу, а не перебором 100+ тыс. зданий |
| Сервер Mini App без состояния в памяти | можно запустить несколько копий |
| Справочники кэшируются на 60 с | не читать таблицы при каждой точке |
| История перемещений не хранится | база не растёт от каждого шага |
| Лимиты Telegram на Mini App не действуют | запросы идут прямо на наш сервер |

## Путь роста

1. Сейчас: один сервер, 2 процесса web, Docker Compose
2. Несколько копий web за балансировщиком, PgBouncer перед базой
3. Redis: частота точек, кэш объектов рядом
4. Отдельный воркер для мировых событий и мобов
5. Нагрузочный тест перед открытым запуском

## Своя подложка карты (№108, план к 3D-карте)

- **Что на сервере:** один статичный файл `bishkek.pmtiles` (~30–80 МБ) + стиль, шрифты, значки. Caddy отдаёт
  его кусками как обычную статику: ни базы, ни Python, ни расчётов — нагрузка на процессор почти нулевая.
- **Трафик:** игрок за день скачивает ~2–10 МБ подложки (телефон кэширует куски, повторно не качает).
  1000 игроков в день × ~5 МБ ≈ 5 ГБ/день ≈ 150 ГБ/месяц. В тариф DigitalOcean $18 (2 vCPU / 2 ГБ) входит
  3000 ГиБ исходящего трафика в месяц — запас ~20 раз.
- **Как собрать файл:** `pmtiles extract` — вырезать прямоугольник Бишкека из готовой сборки Protomaps (секунды,
  без тяжёлых расчётов); или planetiler из выгрузки Geofabrik на ПК. Обновлять — раз в 1–3 месяца.
- **Если игроков станет очень много:** раздавать файл через CDN (Cloudflare / DO Spaces) — меняется только адрес.
